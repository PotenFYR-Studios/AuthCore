🚀 Quick start

1. Download the jar for your Minecraft range and loader
2. Drop it into your server's  mods/  folder  (BungeeCord/Velocity:  plugins/)
3. Start the server - config + SQLite database are created automatically
4. Players are guided through /register and /login in the auth limbo
5. (Optional) switch to MySQL/PostgreSQL/Redis in  config/authcore/settings.conf

❓ FAQ

Is a database required? No - SQLite works out of the box; MySQL, PostgreSQL and Redis are optional upgrades configured in settings.conf.
Does it work with Geyser/Floodgate or proxies? Yes - Floodgate support and Velocity/BungeeCord forwarding are built in; the same jar doubles as a proxy plugin.
One jar for the whole range? Yes - each jar is verified on every endpoint of its range by a real-server Docker test matrix before release.
Where are the config options? ~180 settings documented per version in the configuration reference (see the version docs below).
